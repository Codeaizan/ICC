# Atlas contract

Place the downloaded NCCT ASPECTS atlas here. The initial CLI expects a label volume with integer labels:

`1=caudate, 2=lentiform, 3=insula, 4=internal_capsule, 5=M1, 6=M2, 7=M3, 8=M4, 9=M5, 10=M6`.

Verify the label semantics against the atlas release before use. Record the exact file name, atlas age group, coordinate convention, and SHA-256 checksum in this file. Atlas registration is intentionally not hidden: every case output must include the transform and quality metrics.
